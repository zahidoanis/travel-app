## הרצה מהירה

```bash
npm install
npm run dev
```

נפתח ב-http://localhost:5173. עובד מיד, בלי שום הגדרה ובלי אף מפתח.

| פקודה | מה היא עושה |
|---|---|
| `npm run dev` | שרת פיתוח עם hot reload |
| `npm run build` | בונה ל-`dist/` |
| `npm run preview` | מגיש את ה-build המקומי לבדיקה |
| `npm run ai:check` | מאמת את המפתח ובודק שהדגם באמת עונה |
| `npm run ai:smoke` | מריץ שיחה אמיתית מול Gemini ומדפיס זמנים וטוקנים |

**דרישה:** Node.js 18 ומעלה. נבדק על Node 24.19.0 / npm 11.17.0.

## מה יש באפליקציה

### 1. Onboarding
שלושה שלבים עם סרגל התקדמות. בחירה מרובה של סגנון טיול, בחירה יחידה של תקציב,
וכרטיס סוכן AI צף עם שדה טקסט וכפתור מיקרופון. לחיצה על "הבא" עוברת לדשבורד.

### 2. בית / לו"ז
מזג אוויר, תג סנכרון, כרטיס hero עם "התחל מסלול", **סינון לפי משפחה** שמצמצם את
הלו"ז לעצירות שאותה משפחה משתתפת בהן, ציר זמן אופקי עם נקודות צבע שמראות מי
מגיע לכל עצירה, וקרוסלת המלצות.

### 3. מפה ומסלולים
מפה כהה על מסך מלא עם קו מסלול ציאן זוהר ופינים עגולים לפי קטגוריה.
קרוסלת עצירות בתחתית **מסונכרנת דו-כיוונית** עם הפינים — לחיצה על פין מזיזה את
הכרטיס, והחלפת כרטיס ממרכזת את המפה. כפתור שכבות מחליף בין ספקי אריחים.

### 4. צ'אט AI
התראת עיכוב טיסה, הצעת ניתוב מחדש עם שתי חלופות רכבת, וכפתור אישור שמשנה מצב.
**עם מפתח Gemini התשובות אמיתיות ומוזרמות בזמן אמת**; בלעדיו התשובות מוכנות מראש.
תג בראש השיחה אומר במפורש באיזה מצב אתה.

### 5. גלריה
באנר יצירת סרטון סיכום שפותח מודאל התאמה (מוזיקה, אורך, סגנון עריכה) עם
סימולציית רינדור. רשת masonry דו-טורית עם תג אווטאר של מי שהעלה כל תמונה.

### 6. פיננסים
ממיר מטבע ל-8 מטבעות עם חישוב חי וכפתור החלפה. חלוקת הוצאות קבוצתית עם מתג
**לפי אדם / לפי משפחה** שמשנה את חישוב החובות, ומודאל להוספת הוצאה שמעדכן את
הסכום הכולל ואת המאזן.

### תלויות

`react`, `react-dom`, `vite`, `@vitejs/plugin-react` — וזהו.

האייקונים הם SVG inline והעיצוב הוא CSS עם design tokens. אין ספריית UI, אין
ספריית אייקונים, אין SDK של מפות. זו החלטה מכוונת: פחות תלויות שיכולות להישבר,
ושליטה מלאה על RTL ועל הפיקסלים.

## מפות

**ברירת מחדל: אריחי CARTO Dark Matter — חינם, בלי מפתח, בלי הרשמה.**

Google Static Maps נדחה כי הוא דורש חשבון חיוב עם כרטיס אשראי **גם בתוך המכסה
החינמית**, וללא billing כל תמונה חוזרת עם סימן מים אפור.

במקומו, [`tiles.js`](src/lib/tiles.js) מממש את מתמטיקת Web Mercator
ו-[`MapCanvas.jsx`](src/components/MapCanvas.jsx) מרכיב את האריחים ומניח מעליהם
שכבת SVG עם המסלול והפינים. האריחים והשכבה יושבים באותו element מותמר, כך
שהחלפת עצירה מנפישה `transform` יחיד במקום למקם מחדש 35 אלמנטים.

כפתור השכבות מחליף בין שלושה ספקים חינמיים: CARTO כהה, CARTO כהה ללא תוויות,
ו-OpenStreetMap בהיר.

> **קרדיט הוא תנאי רישיון.** הוא מוצג בפינת המפה. אל תסיר אותו.

> **שימוש הוגן.** אלה endpoints ציבוריים. מתאים לאב-טיפוס ולאפליקציה בהיקף סביר;
> לתנועה גבוהה יש להירשם ל-CARTO / MapTiler / Stadia (לכולם free tier) או לארח
> אריחים עצמאית.

**להוריד מפות מ-Google Maps אסור** — סעיפי "No Scraping" ו-"No caching" בתנאי
Google Maps Platform. פירוט והחלופה החוקית: [FREE-STACK.md](FREE-STACK.md).

Google עדיין נתמך אם תרצה אותו — ראה [MAPS.md](MAPS.md).

## סוכן ה-AI

הצ'אט עובד בשלושה מצבים, לפי מה שמוגדר ב-`.env.local`:

| מצב | תנאי | התנהגות |
|---|---|---|
| **הדגמה** | שום דבר לא מוגדר | תשובות קבועות מראש. ברירת מחדל. |
| **פיתוח** | `VITE_GEMINI_API_KEY` | הדפדפן קורא ל-Gemini ישירות. |
| **פרודקשן** | `VITE_AI_PROXY_URL` | קריאה לפרוקסי שמחזיק את המפתח בשרת. |

כשגם פרוקסי וגם מפתח מוגדרים, **הפרוקסי מנצח**.

### למה צריך פרוקסי

מפתח מפות מוגן בהגבלת referrer, אבל **מפתח LLM שנחשף מאפשר לכל אחד לצרוב את
המכסה שלך**. Vite מטמיע כל `VITE_*` בתוך ה-JS הסופי, כך שבמצב "פיתוח" המפתח
גלוי בקוד המקור של האתר. זה בסדר להדגמה, לא לאתר ציבורי.

### הקמה — מצב פיתוח (5 דקות)

1. היכנס ל-https://aistudio.google.com/apikey
2. **Create API key** — התחבר עם חשבון Google. **אין צורך בכרטיס אשראי.**
3. צור `.env.local` בשורש הפרויקט:

   ```
   VITE_GEMINI_API_KEY=<המפתח שלך>
   ```

4. אמת שהמפתח עובד ובדוק אילו דגמים זמינים לך:

   ```bash
   npm run ai:check     # מאמת מפתח + מריץ קריאה אמיתית לדגם
   npm run ai:smoke     # מדפיס תשובה מלאה עם זמנים וטוקנים
   ```

   `ai:check` מריץ קריאה אמיתית ולא מסתפק ברשימת הדגמים, כי **Google משאיר
   דגמים שהוצאו משימוש ברשימה אבל דוחה אותם למפתחות חדשים** — `gemini-2.5-flash`
   למשל מופיע ברשימה ומחזיר 404 בפועל.

   אם הדגם נדחה, הוסף `VITE_GEMINI_MODEL=<שם מהרשימה>`.

5. הפעל מחדש את שרת הפיתוח — **Vite קורא משתני סביבה רק באתחול**.

עבור לטאב הצ'אט. התג בראש השיחה יראה "סוכן פעיל" ואת שם הדגם.

> **על דגמי חשיבה:** Gemini 3 מוציא מאות טוקנים על "חשיבה" פנימית, והם נספרים
> בתוך `maxOutputTokens`. לכן התקציב עומד על 2048 — עם 400 התשובה נחתכת באמצע
> מילה. חלקי ה-`thought` מסוננים ולא מגיעים לבועת הצ'אט.

### הקמה — מצב פרודקשן

Firebase Cloud Functions דורש את תוכנית Blaze עם כרטיס אשראי, אז הפרוקסי רץ
ב-Cloudflare Workers: **100,000 בקשות ליום בחינם, בלי כרטיס.**

```bash
npm install -g wrangler
cd worker
wrangler login
wrangler secret put GEMINI_API_KEY     # מדביקים את המפתח, הוא נשמר מוצפן
wrangler deploy
```

ערוך את `worker/wrangler.toml` והחלף `<project-id>` בדומיינים האמיתיים שלך
תחת `ALLOWED_ORIGINS` — הפרוקסי דוחה כל origin שלא ברשימה.

ואז ב-`.env.local` של האפליקציה:

```
VITE_AI_PROXY_URL=https://tripai-ai.<subdomain>.workers.dev
```

הסר את `VITE_GEMINI_API_KEY` כדי שהמפתח לא ייכנס יותר ל-bundle.

### מה הסוכן יודע

[`systemPrompt()`](src/lib/gemini.js) מזריק את ההקשר האמיתי לכל שיחה: העיר,
היום מתוך כמה, מזג האוויר, הלו"ז המלא עם שעות ותיאורים, ורשימת המשפחות עם מספר
הנוסעים ומי כבר הצטרף. הכללים מורים לו לענות בעברית, להיות קצר, לא להמציא שעות
פתיחה או מחירים, ולא לטעון שביצע הזמנה — הוא מציע, המשתמש מאשר.

השיחה הפתיחה המתוסרטת מועברת למודל כהיסטוריה, כך שהוא ממשיך את השיחה על עיכוב
הטיסה במקום להתחיל מאפס.

### טיפול בשגיאות

שגיאות מתורגמות לעברית ומוצגות בשיחה עם כפתור "נסה שוב":
חריגה ממכסה (429), מפתח לא תקין, דומיין לא מורשה (403), ודגם שלא נמצא (404,
עם הפניה ל-`npm run ai:check`). סטרים שרץ מבוטל אוטומטית אם עוזבים את המסך.

## שיתוף וסנכרון

### שיתוף בוואטסאפ — עובד

[`share.js`](src/lib/share.js) בונה הודעה עם המסלול, קוד הצטרפות וקישור, ופותח
את וואטסאפ דרך `wa.me` — קישור https רגיל, **בלי SDK, בלי מפתח, בלי WhatsApp
Business API**. במובייל, אם קיים `navigator.share`, נפתחת מגירת השיתוף של מערכת
ההפעלה (שכוללת ממילא את וואטסאפ).

### פיצול לפי אדם או משפחה — עובד

`FAMILIES` ב-[`data.js`](src/data.js) מגדיר את קבוצות הנסיעה, וכל עצירה מחזיקה
`who` — אילו משפחות משתתפות בה. שתי משפחות יכולות לחלוק טיול אחד ולעקוב אחרי
מסלולים חלקית שונים.

בפיננסים, חלוקה **לפי משפחה** מחייבת כל משק בית בחלק אחד ללא קשר לגודלו — הסידור
המקובל כשמשפחות מטיילות יחד.

### סנכרון — עדיין מדומה

כל דפדפן מחזיק state משלו. הקישור כבר נושא `?trip=<id>` ו-`invitedTripId()`
כבר קורא אותו — נקודות החיבור מוכנות.

הדרך החינמית להפוך אותו לאמיתי היא **Cloud Firestore בתוכנית Spark**: סנכרון
בזמן אמת, 50,000 קריאות ו-20,000 כתיבות ליום, בלי כרטיס אשראי. מודל הנתונים
המוצע ב-[FREE-STACK.md](FREE-STACK.md).

כל המשתנים אופציונליים. העתק מ-[`.env.example`](.env.example) ל-`.env.local`

| משתנה | ברירת מחדל | תפקיד |

> **חשוב:** Vite קורא את הקבצים האלה רק באתחול. אחרי שינוי — הפעל מחדש את השרת.

## פריסה

Firebase Hosting, תוכנית Spark — חינם, בלי כרטיס אשראי.

```bash
npm run build
firebase deploy --only hosting
```

[`firebase.json`](firebase.json) כבר מוגדר: `dist` כתיקיית הפרסום, rewrite של
SPA (בלעדיו רענון בנתיב פנימי מחזיר 404), cache immutable על ה-assets ו-no-cache
על `index.html`.

**אל תריץ `firebase init`** — הוא ידרוס את הקובץ.

המדריך המלא מאפס, כולל התקנת Firebase CLI וחיבור הפרויקט: [DEPLOY.md](DEPLOY.md).

## החלטות עיצוב

**RTL עם logical properties.** `inset-inline-start`, `margin-inline-end` וכו׳
במקום `left`/`right`. שים לב שבמכולת flex בכיוון עמודה תחת RTL ציר הרוחב מתהפך:
`flex-start` הוא הצד הימני. לכן בועת המשתמש בצ'אט משתמשת ב-`flex-start` ובועת
הסוכן ב-`flex-end`.

**זום קבוע 14 במפה.** התצוגה עוקבת אחרי עצירה אחת בכל רגע, אז הזום הוא קבוע
עיצובי. התאמה אוטומטית לכל מסלול פריז נוחתת על זום 12, שבו שמות הרחובות בלתי
קריאים. `fitZoom()` נשאר ב-`tiles.js` אם תעבור למסגור של כל המסלול יחד.

**עיגול קואורדינטות ל-5 ספרות** ב-`staticMap.js` — אותו מבט מייצר אותו URL
בדיוק, ולכן נכנס ל-cache של הדפדפן במקום להיות מחויב שוב.

**טוקנים לצבע, מרווח ורדיוס** ב-`:root`. כל הצבעים עוברים דרך משתני CSS, כך
שהחלפת ערכת נושא היא שינוי בבלוק אחד.
